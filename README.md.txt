CRUD Alumnos - Java NIO

Instrucciones de Ejecucion

Opcion 1: Desde Apache NetBeans
1. Abre el proyecto en el IDE Apache NetBeans.
2. Localiza el archivo `Main.java` en tu explorador de proyectos.
3. Haz clic derecho sobre `Main.java` y selecciona "Run File".

Opcion 2: Desde Consola (Terminal)
1. Abre la terminal y navega hasta la carpeta que contiene los archivos `.java`.
2. Compila el codigo ejecutando:
   javac Main.java Alumno.java AlumnoRepository.java
3. Inicia el programa ejecutando:
   java Main
